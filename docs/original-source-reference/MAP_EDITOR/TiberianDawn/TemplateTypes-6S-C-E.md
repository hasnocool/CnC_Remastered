- IDs128–135 are Road36–Road43, tokens `d36`–`d43`; all eight are 2×2 and support Winter, Desert and Temperate.
- IDs136–148 are River1–River13, tokens `rv01`–`rv13`; all support Winter and Temperate. Footprints range from 2×2 to 5×4.
- IDs149–159 are River14–River24, tokens `rv14`–`rv24`; all are Desert-only. River20 is 6×8 and River21 is 5×8, the largest footprints in this slice.
- Every declaration uses the five-argument `TemplateType` constructor. The pinned model's overload delegates to the six-argument overload with `TemplateTypeFlag.None`; every row therefore has Flag=None.
- All declarations are `public static readonly TemplateType` fields. Preserve explicit IDs and source order; do not derive IDs from tokens or alphabetize the families.

## Initialization and consumer context

The shared `TemplateType` model stores a `ushort ID`, `string Name`, integer icon dimensions, theatre array, flag, mutable `bool[,] IconMask` and `Image Thumbnail`. Its `Init(TheaterType)` computes `iconSize = Math.Max(IconWidth, IconHeight)`, allocates a square thumbnail from that maximum, clears a width-by-height mask, then iterates y outer/x inner. A successful `GetTileData(theater.Tilesets, Name, icon, out tile)` draws the tile and sets the corresponding mask cell; if no tile succeeds, `Thumbnail` becomes null.

The shared `Map.InitTheater` iterates every TemplateType and calls `Init(Theater)`. Both TD and RA plugin theatre-change handlers call `Map.InitTheater(GameType)`. These shared bodies were fetched again for this tranche; this catalog slice is not a complete GamePlugin body review.

## Rust mapping and verification boundary

The current `crates/map-editor-model/src/lib.rs` represents the placed template layer only as `CellLayers.template: Option<u16>`. It has no TD TemplateType field/token/theatre/footprint/flag catalog, thumbnail cache or icon mask. The separate `crates/rts-core/src/red_alert_template.rs` implements a partial engine-runtime `TemplateClass` through `TemplateWorld`; it is not the editor's static TemplateType registry.

No Rust mapping is claimed. No Rust tests, C# runtime tests, tile lookup tests, image comparisons or serialization parity tests were executed. The registry remains Partially reviewed.
