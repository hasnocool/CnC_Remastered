## Registry and initialization context previously inspected

The static constructor reflects over public static fields, keeps init-only fields assignable to `TemplateType`, and materializes them with `ToArray()`. `GetTypes()` returns the backing `Types` array as `IEnumerable<TemplateType>`; there is no explicit sort or duplicate/footprint validation in that method. This constructor/GetTypes inspection predates this tranche. The full registry file remains Partially reviewed until every declaration and dependency is covered.

The shared [TemplateType model](../TemplateType.cs.md) and [TemplateTool](../Tools/TemplateTool.cs.md) have already been body-reviewed. `TemplateType.Init` allocates a thumbnail and `bool[IconWidth, IconHeight]` mask, iterates y outer/x inner, and sets a mask cell only after successful tile lookup. `Map.InitTheater` iterates all template types and calls `Init`; TemplateTool consumes theatre availability, thumbnail, dimensions/mask and Clear flag. See [cross-variant comparison](../Variant-TemplateTypes-6S-C-D.md).
