## Shared TemplateType contract and initialization

- `TemplateTypeFlag` is `[Flags]`: None=0, Clear=1<<1, Water=1<<2, OreMine=1<<3; bit 0 has no declared member.
- Public properties: `ushort ID`, `string Name`, `string DisplayName => Name`, `int IconWidth`, `int IconHeight`, `Size IconSize`, `int NumIcons => IconWidth * IconHeight`, `bool[,] IconMask`, `Image Thumbnail`, `TheaterType[] Theaters`, `TemplateTypeFlag Flag`. Most setters are private; IconMask and Thumbnail are public settable.
- The six-argument constructor assigns ID/name/geometry/theatres/flag; the five-argument overload delegates with `TemplateTypeFlag.None`. All declarations in this tranche use the five-argument overload.
- `Equals(object obj)` compares TemplateType through the overloaded equality operator, byte/ushort to ID, strings to Name ordinal-ignore-case, otherwise base.Equals. GetHashCode uses ID; ToString returns Name.
- `Init(TheaterType theater)` uses OriginalTileWidth/4 for icon pixels, allocates a square bitmap from max(width,height), allocates/clears `bool[width,height]`, clears transparent, then loops y outer/x inner with a linear icon index. Successful theatre-specific tile lookups draw the tile and set mask[x,y]. Thumbnail is retained only if any tile is found; mask is assigned regardless. No positive-dimension guard precedes bitmap allocation.
- `Map.InitTheater(GameType gameType)` initializes every TemplateType first, then smudge, overlay, terrain, infantry, unit and building definitions. Dimensions/theatre lookup therefore affect theatre initialization, not only selector presentation.
