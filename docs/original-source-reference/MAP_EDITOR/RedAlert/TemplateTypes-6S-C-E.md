## Verified observations

- IDs128–134 are Falls2a, Ford1/Ford2 and Bridge1/Bridge1d/Bridge2/Bridge2d. Falls2a is 3×2; fords are 3×3; bridges are 5×3 or 5×2.
- IDs135–159 are Slope01–Slope25, with tokens `s01`–`s25`. Field names omit the leading zero retained in the lookup tokens.
- All 32 entries are available in Temperate and Snow.
- Slope21 is 1×2; Slope22 is 2×1; Slope02, Slope06, Slope16 and Slope20 are 2×3; Slope09, Slope13 and Slope23 are 3×2. The other slope entries are 2×2.
- Every declaration uses the five-argument `TemplateType` constructor. The pinned model overload delegates to the six-argument constructor with `TemplateTypeFlag.None`; every row therefore has Flag=None.
- No zero-sized footprint occurs in this slice. This does not erase the separate 0×0 source declarations already documented at IDs100–102 and 111.
- Preserve the source field order and numeric IDs. The sequence changes families at ID128 and must not be sorted by field name or token.

## Initialization and consumer context

The shared `TemplateType.Init` allocates a thumbnail using the maximum icon dimension, allocates a `bool[IconWidth, IconHeight]` mask, and iterates y outer/x inner. Successful theatre-specific tile lookups draw into the thumbnail and set mask cells; missing lookups leave cells false. `Map.InitTheater` invokes this for every registered TemplateType, and the RA plugin's theatre-change handler invokes `Map.InitTheater(GameType)`.

The earlier RA 0×0 entries remain a source-confirmed zero-sized Bitmap request on this shared path. This tranche contains no additional zero-dimension records. No runtime exception or reachability claim is added here.

## Rust mapping and verification boundary

The current Rust editor model stores only `CellLayers.template: Option<u16>`; it does not provide the RA editor catalog, theatre whitelist, footprint, flag, thumbnail or icon mask. `crates/rts-core/src/red_alert_template.rs` is a separate partial port of the engine runtime `TemplateClass`, not the map editor's static `TemplateType` records.
