## Shared TemplateType contract and initialization

TemplateType is the editor's static definition object, not a placed runtime template. TemplateTypeFlag is [Flags] with None=0, Clear=1<<1, Water=1<<2 and OreMine=1<<3 (no declared bit-0 member). Public members include ushort ID, string Name, DisplayName=>Name, int IconWidth/IconHeight, Size IconSize, NumIcons=width×height, bool[,] IconMask, Image Thumbnail, TheaterType[] Theaters and TemplateTypeFlag Flag. Setters are private except IconMask and Thumbnail.

The six-argument constructor assigns ID/name/geometry/theatres/flag; the five-argument overload delegates with None. Equals handles TemplateType via the overloaded equality operator, byte/ushort by ID, strings by ordinal case-insensitive Name, otherwise base.Equals. GetHashCode uses ID; ToString returns Name.

Init(TheaterType) sets each icon's pixel size to Globals.OriginalTileWidth/4, allocates a square Bitmap using max(width,height), creates and clears bool[width,height], then loops y outer/x inner while incrementing the linear icon index. A successful Globals.TheTilesetManager.GetTileData(theater.Tilesets, Name, icon, out tile) draws the tile and sets mask[x,y]. Thumbnail is retained only if any tile is found; the mask is always assigned. There is no positive-dimension guard before Bitmap allocation. Map.InitTheater loops all TemplateTypes and calls Init(Theater), then initializes smudge, overlay and terrain registries.
